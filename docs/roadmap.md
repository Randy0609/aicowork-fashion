# Roadmap

路线图表达方向，不构成交付日期承诺。

## v0.1-alpha：可下载框架

当前候选版包含：

- React 工作台壳；
- FastAPI；
- 模拟与 OpenAI-compatible 模型适配；
- 工作流自动发现；
- 商品内容生成主链；
- 三个品类配置；
- SQLite 任务与产物库；
- Docker Compose；
- 自动测试与 CI。

## v0.1-beta：设计伙伴验证

候选方向：

- 三至五家外部商家完成独立安装；
- 增加内容采纳、修改和废弃反馈；
- 增加产物导出；
- 完善 Windows 和国内网络环境排错；
- 根据实际安装问题修订一键启动方式。

## v0.2：经营简报实验

仅在数据合同被外部企业验证后考虑：

- CSV 聚合数据导入；
- 事实、判断、动作和验证指标分离；
- 明确禁止模型编造经营数字；
- 不包含任何企业专属数据连接器和口径。

## 暂不进入公共稳定版

- 客户级 CRM；
- 手机号、地址和订单明细；
- 自动营销触达；
- 企业专属平台凭据；
- 未经安全评估的工作流在线安装；
- 直接复制任何私有业务模块。
